# Mock-webusb (日本語)

これは、拡張型互換性APIの「webusb」です。

このwebusbはChromeのWebUSBとは異なり、あくまでも互換APIであり、独自の機能などが含まれている場合がありますが、基本的にお使いいただけます。

### 🌐 現在対応しているブラウザ・環境
- pyside6-qtwebengin
- Firefox
