# Mock-webusb (日本語)

これは、拡張型互換性API「WebUSB」です。

ChromeのWebUSBとは異なり、本プロジェクトはあくまでも互換APIとして設計されています。
独自の機能やカスタム機能が含まれる場合がありますが、基本的にはWebUSB互換のAPIとして利用できます。

## 🌐 実装

### 1. Pyside6-webusb

PySide6 / QtWebEngine向けのWebUSB互換実装です。

https://github.com/steck0714/Pyside6-webusb

### 2. fox-webusb

Firefox向けのWebUSB互換実装です。

https://github.com/steck0714/fox-webusb
